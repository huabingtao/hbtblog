# 项目经历

# 神农帮智能助手

项目描述: 该项目是面向农业合作社的数字孪生大屏与 AI Agent 协同管理平台。系统集成了农场资产（地块、作物、农事）的多维数据看板与右侧智能化对话助手，实现了数据可视化与 AI 赋能的深度融合。

技术栈: React / TypeScript / Tailwind CSS / ECharts / SSE / IndexedDB

主要贡献：

  • 负责核心架构设计，通过解析 AI 结构化文本，实现了右侧对话框与左/中侧大屏组件的互操作性（如 AI 推荐某地块时，大屏对应的地图/列表区域自动高亮定位）。
  • 采用 SSE 实现大模型打字机流式输出，支持 Markdown 与表格的渐进式渲染；针对 AI “深度思考”与“工具调用” 的等待期，独立设计了动态骨架屏与步骤条，消除用户等待焦虑。
  • 使用 Tailwind CSS 精细还原科技感暗色调（发光边框、微渐变特效），采用全局 scale 统一缩放方案，完美保障系统在 1080P 及 4K 监控大屏下的像素级等比自适应。
  • 接入多模态能力,实现病虫害图片的直传压缩与 AI 联合诊断，单次核查效率提升 40%。

# 神农天眼 App (uni-app)

项目描述: 服务于农业监管、核查人员的移动端应用，集成地块巡查、任务分发、空间测绘与现场取证等核心功能，实现农业生产过程的数字化监管与闭环管理。

技术栈: Uni-app / Vue3 / TypeScript / Pinia / Vite / Leaflet.js / Webview

主要贡献：

  • 采用 Vue3 Composition API 与 TypeScript 全面重构业务模块，独立封装 za 系列通用组件（如za-inspect-item、za-common-card 等）及核心 Hooks（如 usePagination、useLocation），显著提升代码复用率，降低核心业务模块的耦合度。
  • 针对地图业务逻辑复杂且变更频繁的痛点，采用 Webview 嵌套 H5 的架构方案。通过 postMessage 和 evalJS 自行封装了跨端通信桥接层，使 H5 能够无缝调用 Uni-app 原生的 API（如 GPS 定位、相册、uni.uploadFile 文件上传等），从而将高频迭代的业务与 App 发版解耦。
  • 在 Webview 侧集成 Leaflet.js 引擎，处理农业矢量图层的数据加载与叠加渲染。实现了移动端地块的多边形绘制、多选/反选交互逻辑，并结合设备 GPS 获取实际坐标，辅助业务人员进行实地与数字地块的校验比对。
